# Mechanical Integration Notes

## GoPro mount — forward offset

**Constraint:** the existing camera mounting position restricted usable battery space.

**Change:** adapted the mount geometry to shift the attachment position forward.

**Outcome:** increased available space for battery placement on the frame. No dimensional improvement has been measured or reported here.

## GPS mount — adapted parts

**Constraint:** integrate the GPS module on the MARK7 airframe with a suitable physical mounting solution.

**Change:** combined and adapted existing model elements into a mount for the installed GPS module.

**Outcome:** physical integration of the GPS mounting arrangement. A CompassMot ground test is now documented in the [main README](../README.md#compassmot--motor-induced-magnetic-interference), with 3.99% mean and 12% maximum recorded interference. This supports an initial assessment of the selected compass location, not proof of optimal placement.

## Design provenance & redistribution

Both `.3mf` project files used to develop these adaptations contain third-party starting models. The GoPro model reports a **Standard Digital File License**; the GPS model reports **CC BY-NC-SA**. The project files are therefore not bundled here pending verification of the original source links, license versions, attribution and redistribution permissions. Images and descriptive notes document the original integration work without redistributing those third-party project assets.
